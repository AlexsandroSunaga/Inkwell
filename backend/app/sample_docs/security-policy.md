# Security Policy (Halden Labs, fictional company)

Passwords: use the company password manager. Passwords must be at least 14 characters and must not be reused across systems. Multi-factor authentication is required for email, the code repository and the admin console.

Devices: company laptops use full-disk encryption and lock after 5 minutes of inactivity. Personal devices may only be used for email and chat, and only with the managed mobile profile installed. Report a lost or stolen device to the security team within 1 hour.

Incidents: if you suspect a phishing email, a leaked credential or unusual access to data, report it to security@halden.example straight away. Do not delete the message. The security team confirms receipt within 30 minutes during working hours and keeps a written record of every incident.

Customer data: customer data may only be accessed through approved tools and only when a ticket needs it. Exporting customer data to personal storage is not allowed. Access reviews are done every quarter and access is removed when someone changes team.

Vendors: new software vendors need a security review before any company or customer data is shared with them.
